The world drawer ヘルプ

キャンバスに戻る

言語:

ルール

  • 他人の絵の上に絵を描くのはOKです。ただし塗りつぶしや明らかな妨害行為はNGです
  • 他の人とコミュニケーションを取りながら描きましょう（トップバーのDiscordアイコンからサーバーに参加できます）
  • Xで「#TheWorldDrawer」とつぶやいて作品を共有しよう

基本操作

  • 左クリック / タップで1マス配置（塗る・消す・履歴・設計図はツールで切替）
  • ドラッグ（左・右・中ボタン共通）で移動、ホイール / ピンチでズーム
  • トップバーの座標はカーソル位置のキャンバス座標です
  • パレットの色はタップで選択、選択済みをもう一度押す（PCはダブルクリック）と詳細編集できます（端末に保存）
  • ツールバー上部のハンドルでツールバーを折りたたみ、描画領域を広げられます（設定は端末に保存）
  • スポイトで描かれたマスの色とインクを取得できます（虹色は取得時の表示色。インク未所持は色のみ取得。取得後は塗るツールに戻り、設計図モードとは併用可）
  • 指でのタップは多少のぶれを許容します。ドラッグ（スライド）で移動、ピンチでズームです
  • 自分のカーソルの送信頻度は設定から変えられます（ひかえめ / 標準 / なめらか / とてもなめらか / 超なめらか）。10秒動かさないと他者から見えなくなります
  • 再訪しても前回の表示位置に戻ります

インク

  • 通常：無制限。色指定どおりに塗ります
  • 発光：光って見えます（ダークモードでより強く輝きます）
  • 虹色：色指定なしで虹色に塗ります
  • ゴースト：半透明に塗ります。すでにある色の上に置くと混ざり、同じマスに重ねるほど濃くなります（最大5回）
  • 配置ごとに30%の確率で特殊インクを1〜5マス分獲得します
  • 特殊インクのボタンは複数同時押しできます（発光＋虹色＋ゴーストの3重ねも可）。置くたび選択中の各インクを1消費、通常で上書きすると解除。同じマスへの重ね塗りで濃くなるのはゴーストのみです
  • チョーク：数十分で消える仮ペイント。イベントや一時的な目印に
  • シールド：一定時間、他人に上書きされなくなります。スポイトで色を取って重ねると見た目を保てます。管理者の巻き戻しは対象外です

レベルとクールダウン

配置ごとに経験値を獲得し、レベルが上がるとクールダウンが短くなります。必要経験値は序盤は軽く、後半はやや重くなります（Lv1→2は3マス、Lv4→5は24マス）。

色の詳細指定

塗る色・カーソル色のボタンから詳細パネルを開き、大きなマスと色相バー、RGB・HSV・LCHのスライダーで直感的に指定できます。コード欄に16進数の直接貼り付けもできます。変更はリアルタイムに反映されます。

設計図モード

建築の下書き用です。描いた内容は自分にだけ薄く表示され、サーバーには送信されません（クールダウン・経験値なし）。塗る・消すツールと組み合わせて描画・消去でき、ツールを切り替えてもモードは維持されます（履歴・スポイト中はそちらが優先）。設定から表示/非表示を切り替えられます。内容は端末に保存されます。

履歴と非表示

  • 履歴ツールでマスをタップすると、そのマスの履歴（誰が・どの色・どのインクで・いつ置いたか）が見られます
  • 各ユーザーには不変の固定ID（#xxxxxx）が振られ、履歴の誰が・オンライン一覧の名前に表示されます
  • オンライン一覧のボタンや各マスの履歴から、ID単位で非表示にできます（その人の塗りとカーソルが隠れます。設定は端末内のみ）
  • オンライン一覧は名前・色・国旗のみで、座標は表示しません
  • 国が自動判定できたユーザーはオンライン一覧と履歴に国旗が出ます

アカウント引っ越し

人物ボタンから引っ越しコード＋パスワードを発行すると、別端末で同じアカウントにログインできます（コードの再発行で旧コードは無効化）。ログイン時にこの端末のレベル・インクは引っ越し先と合算され、両方の配置履歴は残って引っ越し先のIDにまとめられます。名前・色は引っ越し先のものを使います（引っ越し先が初期名のままなら引っ越し元の名前・色を引き継ぎます）。元の端末アカウントは削除されます。

国は最終接続地から自動設定されます（手動設定は不可。アカウントパネルで表示/非表示のみ切替可）

初期名は作成時の言語で固定され、全言語圏にそのまま表示されます

テーマ

設定からライト / ダーク / 自動（端末設定に連動）を切り替えられます。グリッド・原点軸・配置可能範囲の表示/非表示も設定から切り替えられます。

荒らし対策

  • 同一IPからの配置は全体で毎分60マスまでの共有上限があります（通常の家族利用には影響しません）
  • Lv5未満は、既存の絵や他のプレイヤーの近く（1000マス以内）にのみ配置できます。配置できる範囲は黄色の破線で囲って表示され、カーソルが範囲外では赤い破線になります（表示は設定でオフ可）。入れない場所で置こうとすると「絵の近くへ移動」ボタンが出ます
  • ログインの連続失敗は一時ロックされます
