world-drawer ヘルプ

キャンバスに戻る

言語:

基本操作

  • 左クリック / タップで1マス配置（塗る・消す・履歴・設計図はツールで切替）
  • ドラッグ（左・右・中ボタン共通）で移動、ホイール / ピンチでズーム
  • トップバーの座標はカーソル位置のキャンバス座標です
  • パレットの色はタップで選択、選択済みをもう一度押す（PCはダブルクリック）と詳細編集できます（端末に保存）
  • ツールバー上部のハンドルでツールバーを折りたたみ、描画領域を広げられます（設定は端末に保存）
  • スポイトで描かれたマスの色とインクを取得できます（虹色は取得時の表示色。インク未所持は色のみ取得。取得後は塗るツールに戻り、設計図モードとは併用可）
  • 指でのタップは多少のぶれを許容します。ドラッグ（スライド）で移動、ピンチでズームです
  • 自分のカーソルの送信頻度は設定から変えられます（ひかえめ / 標準 / なめらか / とてもなめらか / 超なめらか）。10秒動かさないと他者から見えなくなります
  • 再訪しても前回の表示位置に戻ります

インク

  • 通常：無制限。色指定どおりに塗ります
  • 発光：光って見えます（ダークモードでより強く輝きます）
  • 虹色：色指定なしで虹色に塗ります
  • ゴースト：半透明に塗ります
  • 配置ごとに30%の確率で特殊インクを1〜4マス分獲得します

レベルとクールダウン

配置ごとに経験値を獲得し、レベルが上がるとクールダウンが短くなります。必要経験値は序盤は軽く、後半はやや重くなります（Lv1→2は3マス、Lv4→5は24マス）。

配置直後の3秒以内なら取り消しボタンで元に戻せます（使用した特殊インクも返却）。

色の詳細指定

塗る色・カーソル色のボタンから詳細パネルを開き、16進数・RGB・HSV・HSLで直接指定できます。OS標準のカラーピッカーに貼り付けられないコードもここに貼れます。変更はリアルタイムに反映されます。

設計図モード

建築の下書き用です。描いた内容は自分にだけ薄く表示され、サーバーには送信されません（クールダウン・経験値なし）。塗る・消すツールと組み合わせて描画・消去でき、ツールを切り替えてもモードは維持されます（履歴・スポイト中はそちらが優先）。設定から表示/非表示を切り替えられます。内容は端末に保存されます。

履歴と非表示

  • 履歴モードでマスをクリックすると、誰が・どの色・どのインクで・いつ置いたかが見られます
  • 各ユーザーには不変の固定ID（#xxxxxx）が振られます
  • オンライン一覧や履歴からID単位で非表示にできます（その人のインクとカーソルが隠れます。設定は端末内のみ）
  • オンライン一覧に座標は表示しません

アカウント引っ越し

人物ボタンから引っ越しコード＋パスワードを発行すると、別端末で同じアカウントにログインできます（コードの再発行で旧コードは無効化）。

テーマ

設定からライト / ダーク / 自動（端末設定に連動）を切り替えられます。グリッド・原点軸・配置可能範囲の表示/非表示も設定から切り替えられます。

荒らし対策

  • 同一IPからの配置は全体で毎分30マスまでの共有上限があります（通常の家族利用には影響しません）
  • Lv5未満は、既存の絵や他のプレイヤーの近く（1000マス以内）にのみ配置できます。配置できる範囲は黄色の破線で囲って表示され、カーソルが範囲外では赤い破線になります（表示は設定でオフ可）。入れない場所で置こうとすると「絵の近くへ移動」ボタンが出ます
  • ログインの連続失敗は一時ロックされます
