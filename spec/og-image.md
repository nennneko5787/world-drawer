# OGP画像（実装済み）

`GET /og-image.png` は `backend/src/ogp.rs` の軽量レンダを返す。

## 仕様

- 原点中心1200×630・1px1セル: 背景＋32pxグリッド＋原点軸＋実ピクセル。
  ghostは背景と50%混色。チョーク期限切れは除外。読取は原点周辺の上限付き1クエリ。
- PNG符号化はstored-deflateのみの手詰め（依存クレートゼロ）。
  右下バッジは見送り（フォントラスタライザなしのため。グリッド＋軸＋絵で代用）。
- `cache-control: public, max-age=60`。DB失敗時は背景単色＋グリッドの
  フォールバック画像を返す（空bodyにしない）。
